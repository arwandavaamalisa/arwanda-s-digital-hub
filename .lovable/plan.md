# Arwanda Portfolio Rebuild

## Goal
Create a completely new, responsive one-page portfolio that presents Arwanda as an experienced Virtual Assistant and Business Support professional for international clients.

## Build
- Replace the placeholder home page with a structured portfolio covering Home, About, Services, Work, Experience, and Contact.
- Use a warm editorial visual system: ivory backgrounds, charcoal typography, dusty rose accents, subtle borders, restrained motion, and generous spacing.
- Add sticky desktop navigation and an accessible mobile menu.
- Build the hero, credential bar, six service areas, selected work, email marketing workflow, testimonial placeholders, experience timeline, education, tools, recommendation, contact form, and footer.
- Add interactive case-study detail dialogs, testimonial image lightbox placeholders, quick-copy contact actions, and clear form feedback.
- Keep all portfolio data separated from display components so future content updates remain straightforward.
- Add unique home-page metadata and remove template branding.

## Content handling
- Use only the supplied professional history, services, dates, tools, and contact details.
- Do not invent testimonials, campaign metrics, recommendation text, or client outcomes.
- Use polished placeholders for Arwanda’s portrait, campaign screenshots, feedback screenshots, and recommendation letter until real assets are supplied.

## Quality checks
- Verify desktop and mobile layouts, navigation, dialogs, contact interactions, overflow, accessibility labels, and build status.
- Confirm the page remains readable and visually balanced across common screen sizes.

## Technical notes
- Use the existing TanStack Start and Tailwind CSS foundation with small React components and semantic design tokens.
- Keep the site frontend-only; the contact form will open the visitor’s email app because no message delivery service was requested.
