========================================

Overall aesthetic:
- Premium
- Minimal

Avoid:
- Generic AI portfolio aesthetics
- Excessive gradients

- Overly futuristic UI

Visual direction:
Think modern boutique consultancy / personal professional brand rather than a generic freelancer template.

Use:
- Generous whitespace
- Strong typography hierarchy
- Elegant typography
- Subtle borders
- Soft neutral backgrounds
- Carefully selected accent color
- Large editorial-style headings
- Rounded cards used sparingly
- Subtle micro-interactions
- Smooth but restrained animations

Suggested color palette:
- Warm off-white / ivory background
- Charcoal / near-black text
- Soft muted rose or dusty mauve as accent
- Very light warm gray for secondary sections

The website must remain highly readable and accessible.
